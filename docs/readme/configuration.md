# 設定の操作

[README.md](../../README.md) から分割した詳細。

## 使い方

1. 目的に合うカテゴリを開きます。
2. 項目に表示される効果と注意点を確認します。
3. ボタンを押すか、スイッチを切り替えるか、ドロップダウンから値を選んで適用します。

スイッチ項目は、**ON で設定を適用し、OFF で項目ごとの解除値を設定するか、明示設定を削除します**。適用前の値へは復元しません。項目によって動作が異なるため、画面の説明を確認してから操作してください。

各設定には「既定: ON」「既定: OFF」「既定: 環境による／不明」などを表示します。これはこのアプリで扱う設定の標準状態で、現在の状態や推奨値とは別です。状態を取得できない間や処理中は操作できません。

適用値にも解除値にも一致しない設定は「カスタム」と表示し、同じ位置のON/OFF選択欄から、どちらへも直接変更できます。通常のON/OFF状態ではスイッチを表示します。

UWPバックグラウンド実行は「一括OFF」「一括ON」ボタンで、現在インストールされている対象アプリをまとめて禁止・許可します。アプリを追加した後も同じボタンで再適用できます。「一括ON」は明示的な許可であり、Windows標準へ戻す操作とは異なります。Windowsのポリシーやアプリ自体の制約は引き続き適用されます。

ON / OFF では表せない設定は**ドロップダウン**になっています。既定値は設定の説明と「(既定)」付きの選択肢で確認できます。ほかの項目に連動する設定は、その**親項目のカードの中にまとめて表示**され、親が OFF または状態を取得できない間は操作できません。

## クリーンアップ

「クリーンアップ」には、通常・高度・スリム化・設定・その他の 5 つのタブがあります。どのタブも、先に調べて（この間は何も変更しません）、項目ごとの件数とサイズを確認し、選んで、確認してから削除する流れです。調べ直したときや設定を変えたときは前の結果が無効になるので、もう一度調べてから実行してください。

- **通常**: 「おすすめ」は再生成できるキャッシュ・ログ・一時ファイルだけを選びます。履歴やサインアウトを伴う項目、再構築に時間がかかる項目は、自分で選んだときだけ削除されます。Cookie とフォーム履歴は既定ではオフで、選んだときだけ削除します。「すべて選択」には Cookie が含まれ、サインアウトされる旨が表示されます。受信したファイルなど再取得できないものは「すべて選択」に含まれず、個別に選んで再確認が必要です。保存パスワード・認証情報・アプリの設定は対象にしません。
- **高度**: 準備済みのドライブを拡張子で探し、ファイルを選んで削除します。取り外せるドライブは、選んだときだけ対象になります。表示上限を超えた分は削除されません。
- **スリム化**: Windows Update の残骸、使われていない Installer ファイル、言語の入力補助機能などを整理します。実行の前に復元ポイントを作ります（設定で変更できます）。更新のロールバックを削除すると、既存の更新をアンインストールできなくなるため、二段階の確認があります。
- **設定**: 除外するファイル・フォルダー・拡張子とファイル名・Cookie のドメイン（インポート・エクスポートできます）、カスタムフォルダー、安全な削除、復元ポイントの自動作成を設定します。カスタムフォルダーは中身だけを空にし、Windows や Program Files などの保護された場所は追加できません。
- **その他**: アイコン・サムネイル・フォントキャッシュ、検索インデックス、リンク切れのスタートアップ項目・関連付け候補、SSD の最適化などのボタンです。

起動中のブラウザーやアプリを対象にするときは、先に確認が表示されます。「終了する」を選ぶと閉じるよう要求し、閉じない場合だけ、未保存の入力が失われることを示して再確認します。終了を拒んだ項目は飛ばし、成功とは表示しません。

削除はごみ箱へ移さず、完全に削除します。「安全な削除」をオンにすると 1 回上書きしてから削除しますが、SSD では消去を保証しません。使用中のファイルは残し、権限不足は件数と例として表示します。

サインイン時の自動クリーンアップは廃止しました。旧版で登録した自動実行のタスクは、更新後にアプリを管理者として起動すると、その利用者のものだけが自動で取り除かれます。他の利用者のタスクは、その利用者が次にサインインしたときに取り除かれます。

## 時刻同期の設定

NTPサーバーの変更は、WindowsのNTPクライアントが有効で、手動NTP同期を使うPCが対象です。組織のポリシーでサーバーが管理されている場合や、ドメイン同期・同期無効などのモードでは変更せず、理由を表示します。組織で管理されているPCでは管理者に確認してください。
