# Lumin4ti

**散らかった Windows を、ひと灯りで整える。**

Lumin4ti は、Windows 10 / 11 のメンテナンスや設定変更を、分かりやすい画面から行える無料アプリです。コマンドを入力する必要はなく、各項目の効果と注意点を確認しながら操作できます。

[Lumin4ti をダウンロード](https://lumin4ti.kagayoi.com/Lumin4ti-win.msi)（Windows x64）

## できること

- インストール済みアプリや Windows セキュリティの更新・修復
- Windows Update の再取得可能なダウンロード、Windows・アプリの各種キャッシュ・ログ、リンク切れのスタートアップ項目・関連付け候補の安全な整理
- npm / pnpm / NuGet など、開発ツールの再取得可能なパッケージキャッシュの整理（実行環境、プロジェクト本体、設定・認証情報は保持）
- 選んだキャッシュ・ログをサインイン時に自動整理
- 現在接続されていないデバイスの一覧表示と、選択した項目の削除
- メモリ、バックグラウンド動作、電源、描画などのパフォーマンス調整
- マウス、メニュー、フォルダー表示、アクセシビリティなどのシステム設定
- クイックアクセスのピン留め (パス昇順) や環境変数 Path の並べ替え

このほかにも、Windows のメンテナンスに役立つ機能をカテゴリ別にまとめています。

## インストール

1. [署名済みインストーラー](https://lumin4ti.kagayoi.com/Lumin4ti-win.msi)をダウンロードします。
2. ダウンロードした `Lumin4ti-win.msi` を実行し、画面の案内に従います。
3. Lumin4ti を起動し、ユーザーアカウント制御（UAC）が表示されたら内容を確認して許可します。

新しいバージョンがある場合は、アプリが更新を案内します。

## 使い方

1. 目的に合うカテゴリを開きます。
2. 項目に表示される効果と注意点を確認します。
3. ボタンを押すか、スイッチを切り替えるか、ドロップダウンから値を選んで適用します。

スイッチ項目は、**ON で設定を適用し、OFF で項目ごとの解除値を設定するか、明示設定を削除します**。適用前の値へは復元しません。項目によって動作が異なるため、画面の説明を確認してから操作してください。

各設定には「既定: ON」「既定: OFF」「既定: 環境による／不明」などを表示します。これはこのアプリで扱う設定の標準状態で、現在の状態や推奨値とは別です。状態を取得できない間や処理中は操作できません。

適用値にも解除値にも一致しない設定は「カスタム」と表示し、同じ位置のON/OFF選択欄から、どちらへも直接変更できます。通常のON/OFF状態ではスイッチを表示します。

UWPバックグラウンド実行は「一括OFF」「一括ON」ボタンで、現在インストールされている対象アプリをまとめて禁止・許可します。アプリを追加した後も同じボタンで再適用できます。「一括ON」は明示的な許可であり、Windows標準へ戻す操作とは異なります。Windowsのポリシーやアプリ自体の制約は引き続き適用されます。

ON / OFF では表せない設定は**ドロップダウン**になっています。既定値は設定の説明と「(既定)」付きの選択肢で確認できます。ほかの項目に連動する設定は、その**親項目のカードの中にまとめて表示**され、親が OFF または状態を取得できない間は操作できません。

### サインイン時の自動クリーンアップ

「クリーンアップ」カテゴリで自動実行する項目を選び、「サインイン時にクリーンアップを自動実行するタスクを登録」を ON にします。既定では利用者固有の一時ファイルとキャッシュだけが選ばれ、システム側の項目は必要なものを追加できます。

登録したタスクは、登録した利用者のサインイン時にUACを表示せず最高権限で動くため、サービス停止が必要な項目も実行できます。GUIのメンテナンス操作とは同時実行せず、先に始まった処理を優先します。旧版で登録したタスクは、更新後にアプリを起動すると現在の定義へ更新されます。

自動実行の登録はPCにつき1件です。別の利用者が登録済みの場合は、その利用者で解除してから登録してください。所有者を確認できない場合も変更を中止します。「信頼できないインストール状態」と表示された場合は、公式の署名済みMSIからLumin4tiをインストールし直してください。

### 時刻同期の設定

NTPサーバーの変更は、WindowsのNTPクライアントが有効で、手動NTP同期を使うPCが対象です。組織のポリシーでサーバーが管理されている場合や、ドメイン同期・同期無効などのモードでは変更せず、理由を表示します。組織で管理されているPCでは管理者に確認してください。

## 利用前の注意

- システム設定を変更するため、管理者権限が必要です。
- ON/OFF設定は変更前の値をバックアップしません。マシン全体の設定を変更する項目は他の利用者にも影響します。
- Defenderリセットも設定のバックアップを作りません。Path・クイックアクセスの並べ替えはデータ書き換えとしてバックアップを保持します。
- 実行ボタンの操作には、削除やリセットなど元に戻せないものがあります。必要なデータは事前にバックアップしてください。
- 再起動が必要な項目は、画面にその旨が表示されます。
- 処理中はアプリを終了したり、PC の電源を切ったりしないでください。

## うまく処理できないとき

「バージョン情報」の「デバッグ画面を開く」から、CRDebuggerで実行中のログを確認できます。ファイルへのログ保存も継続します。設定変更や選択保存の処理中は、進捗を示すオーバーレイが表示されます。中断できる操作では、そこから中断できます。

- **アプリの一括更新**: 結果に、アプリごとの成功・失敗・安全確認による除外と、終了コード・理由が表示されます。名前や更新チャネルを確認できないアプリは更新を見送ります。使用中のアプリは終了して再実行してください。インストール方式の違いが表示された場合は、発行元の公式インストーラーで更新方法を確認してください。
- **キャッシュの整理**: 使用中や権限不足などで削除できなかった項目は、パスと理由の代表例が表示されます。必要なサービスの停止を確認できない場合は削除を中止し、停止を要求したサービスの復帰を試みます。アイコン・サムネイル・フォントキャッシュの整理後は、Windowsを再起動して再構築を完了してください。使用中で残った選択済みキャッシュは、安全確認できた場合に起動時の再試行を予約します。再試行は最大3回・7日間で、処理できなかったファイルは保持し、結果は次回のアプリ起動時にログへ記録します。
- **設定の保存が停止している**: 設定ファイルを読み込めない場合は原本を保護して保存を止め、サインイン時の自動クリーンアップも実行しません。言語・更新設定やクリーンアップの選択変更は、その起動中だけ有効です。診断ログで原因を確認してください。
- **スイッチや選択欄が操作できない**: 状態を取得できない項目には、操作結果とは別に状態取得のエラーが表示されます。状態を取得できるようになるとエラー表示が消えます。
- **スイッチの変更・解除に失敗する**: 一部だけ変更が残った場合も、操作結果とログに表示される対象・原因を確認してください。

設定の読み込みや変更・実行に失敗した場合は、項目名と原因を診断ログで確認できます。一部だけ処理できた場合や、別の処理が実行中で操作を受け付けられなかった場合も記録します。ログは `%LOCALAPPDATA%\Lumin4ti\logs\` に保存されます。旧バージョンのログは起動時にこの場所へ移され、`legacy-` で始まる名前で保持されます。使用中などで移せないログは元の場所に残り、次回起動時に移行を再試行します。

## 動作環境

- Windows 10 / 11（x64、Intel / AMD の64ビットPC向け）
- 管理者権限
- ダウンロード、更新、一部機能の利用にインターネット接続が必要

追加のランタイムをインストールする必要はありません。日本語・英語を含む 17 言語に対応しています。

開発・検証の手順は [AGENTS.md](AGENTS.md)、内部構造は [DESIGN.md](DESIGN.md) を参照してください。
