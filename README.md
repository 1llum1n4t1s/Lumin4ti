# Lumin4ti

**散らかった Windows を、ひと灯りで整える。**

Lumin4ti は、Windows 10 / 11 のメンテナンスや設定変更を、分かりやすい画面から行える無料アプリです。コマンドを入力する必要はなく、各項目の効果と注意点を確認しながら操作できます。

[Lumin4ti をダウンロード](https://lumin4ti.kagayoi.com/Lumin4ti-win.msi)（Windows 64-bit）

## できること

- インストール済みアプリや Windows セキュリティの更新・修復
- Windows Update の再取得可能なダウンロード、Windows・アプリの各種キャッシュ・ログ、リンク切れのスタートアップ項目・関連付け候補の安全な整理
- npm / pnpm / NuGet など、開発ツールの再取得可能なパッケージキャッシュの整理（実行環境、プロジェクト本体、設定・認証情報は保持）
- 選んだキャッシュ・ログをサインイン時に自動整理
- 現在接続されていないデバイスの一覧表示と、選択した項目の削除
- メモリ、バックグラウンド動作、電源、描画などのパフォーマンス調整
- マウス、メニュー、フォルダー表示、アクセシビリティなどのシステム設定
- クイックアクセスのピン留め (パス昇順) や環境変数 Path の並べ替え

このほかにも、Windows のメンテナンスに役立つ機能をカテゴリ別にまとめています。

## インストール

1. [署名済みインストーラー](https://lumin4ti.kagayoi.com/Lumin4ti-win.msi)をダウンロードします。
2. ダウンロードした `Lumin4ti-win.msi` を実行し、画面の案内に従います。
3. Lumin4ti を起動し、ユーザーアカウント制御（UAC）が表示されたら内容を確認して許可します。

新しいバージョンがある場合は、アプリが更新を案内します。

## 使い方

1. 目的に合うカテゴリを開きます。
2. 項目に表示される効果と注意点を確認します。
3. ボタンを押すか、スイッチを切り替えるか、ドロップダウンから値を選んで適用します。

多くのスイッチ項目は、**ON で設定を適用し、OFF で適用前の状態または Windows の既定へ戻せます**。項目によって動作が異なるため、画面の説明を確認してから操作してください。

ON / OFF では表せない設定は**ドロップダウン**になっています。「(既定)」と書かれた選択肢が Windows の標準です。ほかの項目に連動する設定は、その**親項目のカードの中にまとめて表示**され、親が OFF の間は操作できません（OS 側で一緒に無効になるためです）。

### サインイン時の自動クリーンアップ

「クリーンアップ」カテゴリで自動実行する項目を選び、「サインイン時にクリーンアップを自動実行するタスクを登録」を ON にします。既定では利用者固有の一時ファイルとキャッシュだけが選ばれ、システム側の項目は必要なものを追加できます。

登録したタスクは、登録した利用者のサインイン時にUACを表示せず最高権限で動くため、サービス停止が必要な項目も実行できます。GUIのメンテナンス操作とは同時実行せず、先に始まった処理を優先します。旧版で登録したタスクは、更新後にアプリを起動すると現在の定義へ更新されます。

自動実行の登録はPCにつき1件です。別の利用者が登録済みの場合は、その利用者で解除してから登録してください。所有者を確認できない場合も変更を中止します。「信頼できないインストール状態」と表示された場合は、公式の署名済みMSIからLumin4tiをインストールし直してください。

### 時刻同期の設定

NTPサーバーの変更は、WindowsのNTPクライアントが有効で、手動NTP同期を使うPCが対象です。組織のポリシーでサーバーが管理されている場合や、ドメイン同期・同期無効などのモードでは変更せず、理由を表示します。組織で管理されているPCでは管理者に確認してください。

## 利用前の注意

- システム設定を変更するため、管理者権限が必要です。
- 実行ボタンの操作には、削除やリセットなど元に戻せないものがあります。必要なデータは事前にバックアップしてください。
- 再起動が必要な項目は、画面にその旨が表示されます。
- 処理中はアプリを終了したり、PC の電源を切ったりしないでください。

## 動作環境

- Windows 10 / 11（64-bit）
- 管理者権限
- ダウンロード、更新、一部機能の利用にインターネット接続が必要

追加のランタイムをインストールする必要はありません。日本語・英語を含む 17 言語に対応しています。
